# SSH 登录与公钥管理

入口为「安全中心 → SSH 登录与公钥」，或 `keine ssh [账户]`。公钥管理为 `keine ssh-keys [账户]`，只读诊断为 `keine ssh-check [账户]`。不传账户时默认 root；SSH 菜单和公钥菜单均可切换账户。

## 账户与影响范围

工具仍由 root 运行，目标账户需要明确选择。例如 Azure 使用 `azureuser` 登录后，可执行 `sudo -i`，再运行 `keine ssh-keys azureuser`。工具不创建账户或授予 sudo，不根据 `SUDO_USER` 自动切换目标。

只管理已有、允许交互登录的账户，以及该账户实际使用的标准 `.ssh/authorized_keys`。新建 `.ssh` 为 0700，公钥文件为 0600，归目标 UID/GID 所有；已有普通账户公钥保存后同样归目标 UID/GID 所有，原所有权记录于基线；root 私有目录无法供目标账户访问时停止操作。主目录必须已存在，不自动修复异常权限；拒绝符号链接、硬链接、组/其他用户可写的路径和超过 1 MiB 的公钥文件。

| 操作 | 影响范围 |
| --- | --- |
| 添加、启停、删除公钥、修改限制或备注 | 所选账户的公钥文件；单条限制只影响对应公钥的新连接 |
| 公钥操作时开启认证 | 服务器级 `PubkeyAuthentication yes`；需要修改时在确认前说明，Match 可能覆盖 |
| 登录方式 | 服务器级密码、公钥、键盘交互策略；当前有效值检查针对所选账户 |
| 登录方式中的 root 策略 | 只有选择 root 时调整 `PermitRootLogin`；普通账户操作保留该项 |
| 安全向导与连接策略 | 服务器级端口、认证或连接策略；root 登录限制仅影响 root |

服务器级策略可能影响其他账户及其 MFA。工具保留 `AuthenticationMethods`，所选账户存在组合认证时拒绝套用登录方式；不能据此证明其他账户未受影响。写入通过语法、所选账户有效值和 reload 验证后才报告完成，仍需验证实际新连接。

## 添加、编辑与轮换公钥

1. 在客户端生成密钥，保留私钥。粘贴 `.pub` 的完整一行，或上传 `.pub` 后输入绝对路径。
2. 默认不限来源和转发；可选来源支持一个或多个 IP/CIDR，使用英文逗号分隔。来源是服务器看到的客户端出口地址。
3. 核对目标账户、指纹、来源、转发及认证范围后统一确认。首次接管保存原始基线，保留其他条目；重复指纹（包括停用条目）不会再次添加。
4. 「管理已有公钥 → 选择文件行号 → 详情 / 修改限制与备注」可修改或解除来源限制，独立禁止或解除 TCP、Agent、X11 转发限制，修改备注。来源输入 `-` 解除限制，备注输入 `-` 清空；留空取消。
5. 保留当前连接，在另一个客户端窗口验证新密钥和限制，再停用或删除旧公钥。

列表展示指纹、备注、算法、来源、三种转发限制及其他原生选项名称。解除某条公钥限制不代表服务端允许该能力；额外选项用 `*` 提示。`restrict` 和原生转发例外可能改变开关语义，这类条目的转发设置保留原生管理，仍可修改来源和备注。其他选项（如强制命令、终端限制和有效期）保留，不执行其中的命令。

支持普通 Ed25519、RSA（至少 2048 位）、ECDSA 和 OpenSSH 安全密钥公钥。导入不接受私钥、SSH 证书、多行内容或预置选项。已有包含原生选项的条目按可解析程度展示；重复、损坏或无法安全修改的选项停止编辑。

停用使用 `# keine-disabled ` 注释，启用恢复原行。编辑限制或备注保留启停状态，不自动切换认证策略。拒绝停用或删除最后一把可解析的启用公钥；公钥数量和指纹不能证明真实登录可用。来源、有效期、强制命令、CA、Match、账户和算法策略都会影响认证。

## 冲突与恢复

修改使用互斥锁、摘要复核、同目录原子替换和首次基线。公钥与恢复记录按账户路径隔离。添加或启用公钥需要开启认证时，认证验证失败也回退本次公钥；检测到事务期间外部修改则保留恢复副本，停止覆盖。

手动改过已接管文件后，脚本停止后续覆盖和撤销。恢复基线可能移除后来添加的凭据，需要确认其他登录手段可用。恢复中心按路径重新识别目标账户，账户不存在或无法唯一识别时保留记录。新建的空 `.ssh` 目录保留，避免删除后来创建的资源。

`--dry-run` 仅预览。入站公钥管理不创建客户端私钥、定时任务或后台监控；自定义公钥路径、`AuthorizedKeysCommand` 和 CA 保留原生管理。删除、停用和恢复公钥不会自动关闭公钥认证；认证配置通过“恢复认证与端口”单独撤销。

## 登录诊断与验证边界

诊断显示所选账户的认证要求、Allow/Deny、强制命令、Chroot、取钥路径、密码状态、文件权限和近期错误。SSH 会话复用当前连接来源；控制台模拟 127.0.0.1。其他来源的 Match、服务启动 `-o` 参数、DNS Host 匹配、PAM 和云防火墙需要进一步核对。普通账户的诊断不会把 root 禁止登录视为该账户的错误。

登录分析支持 1、24、168 小时和刷新，识别密码、公钥及键盘交互失败。统计只涵盖 journal 指定时段内最近至多 5000 条记录，按事件计数，不能视为唯一登录尝试数；无记录不证明没有攻击。来源处置保护当前 SSH 来源。

离线回归覆盖原生公钥解析、账户路径与 UID/GID、账户隔离、限制编辑和原生选项保留、最后公钥保护、外部冲突、事务回退、恢复入口和认证范围。尚未在真实 Debian/Ubuntu VPS 验证此次多账户流程，正式收紧前需保留服务商控制台并验证所需账户的新连接。

格式和选项参考 [OpenSSH sshd 手册](https://man.openbsd.org/sshd.8) 与 [sshd_config 手册](https://man.openbsd.org/sshd_config.5)，以目标 VPS 安装版本的实际校验为准。

## SSH 出站连接

入口为 SSH 安全中心的「SSH 出站连接」或 `keine ssh-client`，快捷连接为 `keine ssh-connect 名称`。这部分管理本机 root 发起的客户端连接，与入站管理所选账户独立；远端账户可以是 root 或普通用户。

1. 选择「生成密钥」，输入名称；由原生 `ssh-keygen` 询问私钥口令，建议设置。
2. 将显示的公钥添加到远端账户的 `authorized_keys`，例如在远端使用 `keine ssh-keys 账户`。私钥留在发起连接的 VPS。
3. 新建连接，填写 IP/域名、端口、远端账户和显示的私钥绝对路径。也可引用已有 root 私钥；填写 `none` 使用交互密码认证。
4. 连接时核对远端主机指纹，登录后通过 `exit` 返回。密钥认证失败不会静默改用密码。

连接、专用密钥和主机记录位于 root 主目录的 `.ssh/keine-client/`，通常为 `/root/.ssh/keine-client/`。新目录 700、私钥 600；拒绝链接、硬链接、非 root 所有者和不安全写权限。连接文件纳入首次基线与冲突保护。私钥不进入常规配置备份和变更基线，不输出私钥内容，不保存密码或私钥口令。卸载、撤销连接和清理项目状态均保留专用密钥与主机记录；用户需另行保管、备份这些凭据。

连接使用独立客户端参数及主机记录，不读取客户端配置、不使用 SSH Agent、不复用连接、不启用端口/Agent/X11 转发，也不创建后台进程。首次主机身份由 OpenSSH 交互确认；身份变化停止连接，需先通过对端控制台核实，工具不会自动清除 `known_hosts`。此模式保留交互终端；暂不提供跳板链、隧道、远程命令批量执行或自动公钥部署。

删除连接保留密钥。删除专用密钥前检查全部连接引用与文件摘要；外部修改或无法解析的连接会阻止删除。已有外部私钥仅供引用，不由工具删除。删除本机密钥不会撤销远端公钥，其他私钥副本仍可登录。

原生命令语义参考 [OpenSSH 客户端](https://man.openbsd.org/ssh.1) 和 [ssh-keygen](https://man.openbsd.org/ssh-keygen.1)。离线测试使用合成占位文件与命令替身，不生成真实私钥、不连接远端。
