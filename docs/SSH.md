# SSH 登录与公钥管理

入口为「安全中心 → SSH 登录与公钥」，或 `keine ssh`。公钥管理可直接运行 `keine ssh-keys`，只读登录诊断为 `keine ssh-check`。

## 添加与轮换公钥

1. 在自己的电脑生成密钥，保留私钥；将 `.pub` 文件中的一整行粘贴到添加公钥页面，或先上传 `.pub` 到 VPS 再输入绝对路径。
2. 默认不限来源和转发；需要时进入可选限制设置，填写来源 IP/CIDR 或关闭 TCP、Agent、X11 转发。关闭转发可能影响 SSH 隧道及 VS Code 远程连接。
3. 核对指纹、来源、转发及认证状态后统一确认。首次接管说明合并在此处，工具保存首次基线并保留其他条目；重复指纹（含停用条目）不会再次添加。
4. 保留当前连接，在另一个客户端窗口使用新私钥登录成功后，再选择旧公钥的文件行号停用或删除。

只写入 root 主目录的 `.ssh/authorized_keys`，并确认该路径存在于当前 root 上下文的 `AuthorizedKeysFile`。支持普通 Ed25519、RSA（至少 2048 位）、ECDSA 和 OpenSSH 安全密钥公钥；导入不接受私钥、SSH 证书、多行文件或自带选项。已有包含选项的公钥可按行启停或删除，其他选项不被重新生成。

停用使用 `# keine-disabled ` 注释，启用恢复原行。拒绝停用或删除本文件最后一把可解析的启用公钥；删除或停用前仍必须确认另一把公钥可登录。解析、条目数量和指纹均不能证明真实登录可用：`from`、过期时间、强制命令、CA、Match、账户和算法策略都会影响认证。全部用户公钥资产保留只读入口，不修改其他账户。

## 写入、冲突与恢复

修改使用互斥锁、摘要复核和同目录原子替换，文件为 0600，缺失的 `.ssh` 目录按 0700 创建。已有 root 主目录、`.ssh` 和公钥文件必须由 root 持有，禁止组或其他用户写入；拒绝符号链接、硬链接和超过 1 MiB 的文件。异常权限只诊断，由管理员通过控制台核对后修复。

添加或启用公钥时，如果有效配置为 `PubkeyAuthentication no`，会同步改为 `yes`，通过语法、有效值检查及 reload 验证；已开启时不重复写认证配置或 reload。密码认证、root 登录权限和 MFA 要求保持原样。此前已添加公钥但认证未开启的用户，可在公钥管理中直接选择“开启公钥认证”。若 `PermitRootLogin no`，页面会单独提示仍需调整 root 登录权限。

认证修改失败会尝试回退认证配置和本次公钥修改；检测到事务期间的外部修改时停止覆盖，保留恢复副本。首次基线纳入项目变更记录，后续外部修改会阻止继续写入和撤销。恢复公钥基线可能移除后来添加的凭据，必须先确认其他登录手段可用。新建的空 `.ssh` 容器目录保留，避免删除后来创建的其他资源。

`--dry-run` 只预览。不会创建客户端私钥、定时任务或后台监控，也不接管自定义公钥路径、`AuthorizedKeysCommand`、CA 或多用户配置。删除、停用和恢复公钥不自动关闭公钥认证；认证设置的首次基线仍通过“恢复认证与端口”撤销。

## 登录方式与诊断

登录方式提供“仅公钥”和“公钥或密码”，与端口向导共用认证 drop-in。重新允许 root 密码需要明确确认并检测到已设置、未锁定的密码。两种操作都不覆盖 `AuthenticationMethods` 组合认证要求；认证向导收紧设置也保留该边界。配置通过 `sshd -t`、当前 root 连接上下文有效值和 reload 后服务状态验证，失败尝试回退；真实连接仍须客户端验证。

诊断显示认证要求、Allow/Deny、强制命令、Chroot、取钥路径、密码状态、路径权限及已知日志错误。SSH 会话使用当前来源上下文；控制台使用 root / 127.0.0.1 模拟上下文，其他来源的 Match 规则可能不同。服务启动命令的额外 `-o`、DNS Host 匹配、PAM 和云端访问规则需要结合原生配置检查。

登录分析支持 1、24、168 小时和刷新，识别密码、公钥及键盘交互失败，联动来源处置、公钥管理与诊断。范围为 journal 指定时段内最近至多 5000 条记录；按事件计数，不能视为唯一登录尝试数，无记录也不能证明没有攻击。来源处置继续保护当前 SSH 来源。

## 验证范围与参考

离线回归覆盖公钥原生解析、输入拒绝、最后公钥保护、外部冲突、事务回退、首次基线恢复和认证策略保护。未在真实 Debian/Ubuntu VPS 上验证此次新增登录流程；正式收紧认证前必须保留服务商控制台和当前会话。

格式与选项以 [OpenSSH sshd 手册](https://man.openbsd.org/sshd.8) 和 [sshd_config 手册](https://man.openbsd.org/sshd_config.5) 为参考，并以目标 VPS 已安装版本的实际校验为准。
