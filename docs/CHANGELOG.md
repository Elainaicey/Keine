# Changelog

## 0.5.2

- 修复 sudo/su 到 root 后，美化仍写入普通用户主目录的问题；目标以有效运行用户为准，主目录与登录 Shell 从系统账户记录读取，菜单和完成提示明确用户
- 提示符只复用目标用户或标准系统目录内的程序，不再通过继承 PATH 误用其他用户的私有引擎；root 的安装、配置和所有权标记独立保存
- 删除依赖已齐全时笼统的“已经安装”提示；Starship 与 Oh My Posh 安装、更新及复用前验证可执行程序和版本，实际配置通过后才提示成功，预览模式不冒报完成
- Bash 登录桥接按用户与 Shell 进程识别加载状态，避免 sudo/su 继承初始化标记导致 root 提示符不生效；重复切换替换托管块，保留自定义配置

## 0.5.1

- 单项软件安装取消重复确认：选择后直接刷新索引、检查候选版本与依赖事务并安装；官方 Release 和官方 APT 安装采用一致操作，保留来源接管和冲突包移除确认
- APT 安装在实际执行阶段增加 `--no-remove`，防止索引或依赖变化导致意外卸载其他软件；保留来源、完整性、状态验证和预览模式
- 所有功能菜单统一加入 `H` 首页，操作结果页也可直接回首页或退出；结束原子菜单调用链，保留预览与无颜色模式，不递归叠加菜单进程
- 返回栏统一展示 `0` 返回、`H` 首页、`Q` 退出，首页不重复显示首页入口；同步安装按钮文案、命令帮助与安全边界说明

## 0.5.0

- 首页品牌统一为 KEINE，更新版本标识与终端视觉组件；菜单键统一使用 `[1]` 格式，数字、字母与两位编号在括号外对齐
- 功能菜单统一返回与退出栏：`0` 返回上层，`Q` 退出工具；首页保留 `0` 退出，菜单选择与普通配置输入分别处理
- 软件中心采用统一分组导航，补齐返回与退出入口，移除重复搜索教程和快捷键枚举；分类仅展示名称与数量
- 软件列表突出名称、状态与版本，软件详情只展示当前可用操作；来源元数据、校验和运行说明移入按需安装信息页
- 精简系统、网络、安全、应用、容器、终端和备份页面的重复说明；保留配置输入格式、运行影响与危险操作确认
- 修复存储扫描范围选择的输出捕获问题，菜单直接显示并在当前 Shell 处理退出；中文宽度测量排除 ANSI 颜色序列，长名称状态自动退为纵向布局

## 0.4.0

- 软件中心区分本地索引待确认与刷新后无候选版本，缺失索引不再阻止安装前的确认和事务预览；增加包名搜索、详情与列表刷新、发行版来源诊断，避免把本地状态称为上游最新
- 增加声明式软件指南与关联入口，Nginx 可直达 Certbot 插件；客户端依赖由 APT 解析，安装不隐式签发证书或修改站点
- 软件目录增至 281 项、官方 Release 增至 20 项：Micro 默认官方稳定版，新增 Go 版 yq；显式更新重新查询上游，继续严格校验官方地址、架构和 SHA-256
- 应用菜单批量读取 systemd 与包版本，复用内存快照并支持 R 刷新；移除详情的隐式端口扫描和已知包版本的冗余程序探测
- 容器详情合并 inspect、Compose 合并状态列表，操作后重新读取；Docker 只读查询添加超时，移除子菜单返回的多余等待，终端文本宽度使用有界内存缓存

- 历史配置快照改为手动创建，支持托管配置、常用系统配置与指定文件；仅保留独立首次撤销基线，事务临时副本退出时删除；Docker 卷恢复不再自动复制业务数据
- 主导航收敛为九个领域中心，系统基础设置前置，终端与美化归入系统；网络设置、连接和诊断按任务拆分，备份统一入口，删除重复项目撤销入口
- 修复首次安装提示符时目录记录被前置命令提前消费，导致安装成功但配置切换失败；按实际写入阶段登记和提交目录、引擎与状态标记
- 项目、GitHub 仓库、命令入口、安装路径与环境变量统一使用 keine
- 修复提示符只写入 Zsh 配置导致 Bash 不生效的问题；Starship/Oh My Posh 按登录 Shell 初始化，补齐 Bash 登录入口，新增生效诊断与原始配置恢复；Zsh 专属项目单独确认 Shell 切换
- SSH 新增九项连接和转发策略，逐项更新保留现有认证参数，验证最终值后 reload，失败回退；密码关闭前要求公钥登录验证
- Fail2ban 新增持久 sshd Jail 策略、封禁/观察窗口/重试参数和白名单，保护当前 SSH 来源并核对运行值；可恢复项目配置，保留外部 Jail
- UFW 增加批量拒绝规则与原生 TCP 连接限速，拒绝覆盖当前 SSH 端口；配置写入共用事务移入 core，减少领域重复实现

- 网络中心新增系统 DNS 配置：识别 resolved、resolvconf 和普通文件，支持公共/自定义地址、解析验证、失败回退与基线恢复；不覆盖未知网络管理器的生成文件

- 新增七项可撤销内核网络参数、持久来源查询及第三方调优预留适配入口；未选择上游时不下载或执行脚本

## 0.3.0

- 收紧安装、卸载、备份和状态目录的路径规范化边界，拒绝尾随斜杠、重复斜杠、控制字符及等价系统顶层目录

- Swap 创建升级为事务式流程；创建、初始化、状态记录、启用或 fstab 写入失败时会安全回滚已创建资源

- 按单 root VPS 定位移除账户管理、`users` / `user` 命令、Crontab 页面、systemd Timer 管理及 `timer` 命令
- 合并系统仪表盘、健康巡检、环境检查和项目检查的重复路径：保留仪表盘与故障排查，统一使用 `keine doctor` 检查运行环境和项目完整性
