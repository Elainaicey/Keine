# keine 0.6.2

0.6.2 修复项目管理自更新后，当前控制台仍显示旧版本并继续使用已加载旧代码的问题。

## 更新体验

- 菜单更新成功后，按 Enter 加载新版并进入首页，或按 Q 退出。
- 通过替换当前进程完整重载功能代码、版本与菜单，保留无颜色选项；不创建后台进程，不重启 VPS。
- 同版本重新部署也会重载，覆盖版本号未变化但代码已更新的情况。
- 命令行 `keine self-update` 成功后返回终端，不自动打开菜单。
- 取消、下载或安装失败、`--dry-run` 预览不触发重载。完成提示采用实际安装版本，入口验证失败时不会继续旧控制台。

## 首次升级

从 0.6.1 或更早版本升级到本版本时，自更新仍由旧进程执行，需要最后手动退出并重新运行一次 `keine`。之后通过新版菜单更新即可使用回车重载流程。
