# keine 0.6.7

0.6.7 修复公钥添加与认证开关脱节的问题，并精简 SSH 中心的操作界面。

- SSH 菜单固定单列，公钥列表与操作分区；页面显示公钥认证的有效状态。
- 添加、导入或启用公钥后，按需开启 `PubkeyAuthentication`；配置验证或 reload 失败时尝试回退本次操作。已开启时不重复 reload。
- 已有公钥可直接选择“开启公钥认证”，无需切换整套登录方式。
- 来源与转发限制收进可选设置；接管说明与最终操作合并确认，保留首次基线、最后公钥与外部修改保护。

## 升级

运行 `keine update`，更新后 `keine version` 显示 `0.6.7`。升级本身不修改 SSH 设置；从 `keine ssh-keys` 管理已有公钥及认证状态。

## 兼容性与变更

同步开启只修改公钥认证开关，密码、root 登录权限、MFA 要求和其他限制保持原样。`PermitRootLogin no` 仍会禁止 root 登录，页面单独提示；公钥基线恢复与认证基线恢复分别提供入口。

离线回归覆盖认证开启、参数保留、失败回退和界面流程。尚未在真实 VPS 上验证本次登录流程，请保留当前会话并另开窗口验证。

详见 [SSH 登录与公钥](../SSH.md)。
