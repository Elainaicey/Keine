# keine 0.4.0

0.4.0 继续围绕单人管理的 Debian / Ubuntu VPS 打磨按需运维流程：更明确地呈现软件安装的联带变更与运行影响，减少重复查询，并让大型软件目录和应用服务页面更容易操作。

## 版本重点

- 项目统一使用 keine，新命令 `keine`、安装目录 `/opt/keine`，环境变量统一使用 `KEINE_*`。
- 修复 Bash 登录时 Starship 不生效的问题，新增 Bash/Zsh 启动适配、生效诊断、初始化语法验证及原始终端恢复。
- 安全中心增加 SSH 连接/转发策略、Fail2ban 持久 SSH 防护策略与白名单，以及带 SSH 保护的 UFW 拒绝规则和 TCP 连接限速。

- 网络中心提供原生系统 DNS 切换与恢复、已有 SOCKS5 出站配置，以及逐项可撤销的网络参数；新增命令 `dns-config`、`proxy`、`proxy-check` 与 `net-tuning`。
- DNS 根据原生后端应用并验证；SOCKS 配置仅在显式使用时生效，不影响全局路由或节点软件。BBR 同时恢复原始算法和默认队列。
- 预留第三方网络调优适配入口与参数来源查询；尚未选择上游，不下载或执行外部脚本，外部冲突不会被强行覆盖。
- 软件目录扩充为 281 项、15 个用途分类，官方 GitHub Release 为 20 项；独立工具默认官方直装，终端外观另设中心。
- 新增系统更新中心：完整刷新索引、核实发行版来源、预览并确认更新；保留 hold，禁止自动移除软件与重启。
- 修复空 APT 包名引起的数组下标错误，已卸载包的残留配置不再误报为安装状态。
- 终端项目支持安装并切换和初始配置恢复；原生集成识别已有 WARP/wgcf，不以项目安装标记限制控制。
- 新增可逆修改记录和第三种卸载模式：恢复已记录配置与设置，移除可确认的新增资源，冲突时停止。
- 交互式软件中心统一使用分页浏览，可用页内编号或 ID 打开详情；`keine software [ID]` 提供直接入口，`keine list` 保留完整输出。
- APT 安装及可模拟的更新、移除会在确认前展示事务计划；安装或更新若意外包含移除项，将停止执行。
- 软件详情和安装确认展示已知的上游服务、Socket、调度和网络影响。keine 本身仍不创建后台监控或自动任务。
- Docker 与 Caddy 的官方仓库提供按需配置、来源诊断、候选版本验证及显式修复；Docker 迁移先确认目标组件可用，再处理冲突包。
- 应用中心将 11 类服务按领域整理，加入运行健康、资源与关联监听，并在详情中提供经过确认和结果验证的生命周期操作。
- 运维总览新增状态驱动的关注项和快捷入口；网络中心加入一次性 HTTP/HTTPS HEAD 诊断与更一致的 TCP 端点探测。
- 终端页面针对较长指标和操作名称自动退为纵向布局，避免窄终端挤压错位。

## 兼容性与变更

- 支持 Debian 11、12、13 和 Ubuntu 22.04 LTS、24.04 LTS，要求 systemd；目标架构为 amd64 与 arm64。
- 软件安装仍一次只接受一个 ID，修改系统前仍需人工确认；官方 Release 继续校验来源资产和 SHA-256。
- 工具安装不会自动更改已有软件、服务、SSH、防火墙或计划任务。
- 0.4.0 的项目文件与系统软件状态是两回事；升级工具本身不会批量升级软件中心的条目。

## 升级

已安装 keine 可运行 `keine self-update`。新安装可在版本标签发布后使用：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Elainaicey/keine/refs/tags/v0.4.0/install.sh)
```

升级后建议运行 `keine version`、`keine doctor` 和 `keine status`。涉及 SSH、UFW、Swap、Docker 与 systemd 的写操作，请先保留服务商控制台或实例快照，再在实际 VPS 上逐项验证。
