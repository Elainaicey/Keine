# keine 0.5.1

0.5.1 优化单项软件安装与全局导航，减少重复确认和逐层返回，保留来源校验、依赖检查与危险操作保护。

## 版本重点

- 选择软件安装后，自动刷新来源并直接安装；不再分别确认索引刷新和安装执行。
- 发行版软件安装仍校验候选版本、展示依赖事务，并在模拟与实际执行阶段阻止意外移除其他软件。
- 官方 Release 与官方 APT 渠道取消普通安装确认，仍保留上游、架构、签名或 SHA-256 验证。
- 所有功能菜单统一提供 `0` 返回、`H` 首页与 `Q` 退出；操作结果页同样支持直接回首页。
- 首页跳转结束原子菜单调用链，保留预览和无颜色模式，不创建后台进程或递归叠加菜单。

## 兼容性与变更

- `keine install ID` 直接执行单项安装；如需仅查看命令，使用 `keine install ID --dry-run`。
- 软件更新、移除、来源接管、冲突包移除和高风险配置继续保留确认。
- `H` 和 `Q` 仅用于菜单及操作结果页，不改变主机名、地址等普通配置输入的含义。
- 命令仍为 `keine`，安装目录仍为 `/opt/keine`；不新增后台监控、自动安装套餐或计划任务。
- 升级工具不自动安装目录软件，也不修改 SSH、防火墙或业务服务。

## 升级

已安装实例：

```bash
keine self-update
keine version
```

从 main 安装：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Elainaicey/keine/refs/heads/main/install.sh)
```

版本标签发布后，可将安装地址中的 `refs/heads/main` 替换为 `refs/tags/v0.5.1`。
