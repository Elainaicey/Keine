# keine 0.5.0

0.5.0 聚焦终端界面的统一与精简。主导航、软件中心和各功能页面采用一致的菜单键、间距与返回方式，减少重复说明，将状态、版本和可执行操作置于更清晰的位置。

## 版本重点

- 首页品牌统一为 KEINE，清除旧横幅名称。
- 菜单键统一使用 `[1]`、`[10]`、`[R]` 格式，括号内部不留空格；中文标签、状态与双列操作按终端显示宽度对齐。
- 功能菜单统一提供 `0` 返回与 `Q` 退出；首页使用 `0` 退出。
- 软件中心与其他功能中心采用同一套分组、菜单和退出栏，保留名称或 ID 搜索，不再展示冗长的操作教程。
- 分类只展示名称与数量；软件列表优先展示名称、状态和版本，详情只列当前可用操作。
- 软件来源路径、完整性和运行影响的详细说明收纳到安装信息页；Nginx 继续保留 Certbot 关联入口。
- 精简各领域的重复说明，保留输入格式、风险边界与修改确认。
- 修复存储扫描范围选择的菜单隐藏与返回值污染；排除颜色序列对显示宽度的干扰，长名称状态自动换行。

## 兼容性与变更

- 支持范围、安装渠道和系统修改策略不变，命令仍为 `keine`，安装目录仍为 `/opt/keine`。
- `Q` 仅作为菜单退出键，不改变主机名、地址、关键词等普通配置输入的含义。
- 工具仍完全按需运行，不新增后台进程、自动任务或周期监控。
- 升级工具不会批量更新系统软件，也不会自动修改 SSH、防火墙或业务服务。

## 升级

已安装的实例可执行：

```bash
keine self-update
keine version
```

从 main 安装：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Elainaicey/keine/refs/heads/main/install.sh)
```

发布版本标签后，可将安装地址中的 `refs/heads/main` 替换为 `refs/tags/v0.5.0`。
