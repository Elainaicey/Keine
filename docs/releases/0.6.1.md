# keine 0.6.1

0.6.1 扩展网络调优的实际管理能力，在保持两套参数算法独立的同时，将按需测量、队列、出口整形与初始窗口纳入同一套交互和恢复流程。

## 网络测量

- 对指定 iperf3 服务端执行四流带宽探测，或单流/四流效果验证。
- 按明确的带宽区间执行粗扫、细扫与重传异常复测；对端过慢、结果缺失或拐点不稳定时不生成整形建议。
- 比较最多八个用户提供的对端延迟，不维护或扫描公共测速节点库。
- 每次测量显示目标、时长与流量影响；扫描只给出候选值，不自动套用限速。

## 队列与路由窗口

- FQ 实际队列切换；保留 mq 多队列结构并逐一配置叶队列。
- HTB + FQ 网卡总出口整形，显示对 SSH、UDP 与代理业务的影响。
- IPv4/IPv6 单一路径默认路由的 initcwnd / initrwnd 管理，保留网关、来源与路由优先级。
- 首次基线、并发互斥、结果核对、失败恢复与外部修改保护；恢复中心和撤销后卸载共用同一份记录。

## 运行边界

sysctl 方案仍由原生 sysctl.d 持久加载。队列和初始窗口仅当前启动周期有效，重启后不自动重放；没有新增服务、Cron、Timer、内核安装或后台测速。未知队列、外部 tc filter、动态到期或多路径默认路由不自动接管。

按需测量需要 iperf3、jq、iproute2 和 GNU timeout；对端必须提供允许使用的 iperf3 服务。测速会消耗带宽，整形会影响整张网卡，应保留云平台控制台并避开业务高峰。

## 开发检查

精简重复结构断言，保留安全与失败恢复覆盖。支持按修改范围运行回归；此版本新增的运行事务测试使用临时目录与网络命令替身，不修改测试宿主机的真实网络。

完整操作说明见 [网络调优方案](../NETWORK-ADAPTERS.md)。
