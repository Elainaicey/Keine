# keine 0.5.2

0.5.2 修复终端美化的安装提示与用户归属，改善云主机通过 sudo/su 进入 root 后的提示符配置。

## 版本重点

- 配置目标采用当前有效用户，不再优先使用 sudo 发起用户；root 会话将引擎、配置与所有权标记保存在 root 的主目录。
- 终端菜单和完成提示明确配置用户，只复用该用户或标准系统目录内的程序，避免继承 PATH 指向普通用户私有引擎。
- 依赖已经齐全时保持静默，不再出现容易误解为 Starship 安装完成的笼统提示。
- Starship 与 Oh My Posh 安装、更新和复用时验证程序及版本；只有真实配置通过才报告成功，预览模式不报告已经安装或配置。
- Bash 登录桥接按有效用户与 Shell 进程识别初始化状态，保留自定义配置并避免重复托管块。

## 兼容性与变更

- 命令仍为 `keine`，安装目录仍为 `/opt/keine`；不新增后台监控、自动任务或批量配置。
- `sudo keine terminal` 的配置目标为 root；普通用户已存在的美化不会被自动复制、覆盖或删除。
- 更新工具本身不会自动应用主题。需要在目标用户下重新选择引擎切换，再打开该用户的新 Shell；无需重启 VPS。
- Oh My Zsh、Spaceship 的 Zsh 要求、登录 Shell 修改确认及原始配置恢复边界保持不变。

## 升级

```bash
keine self-update
keine version
```

云主机以普通用户登录时，进入 root 后重新应用美化：

```bash
sudo -i
keine terminal
```

选择 Starship 安装并切换，退出工具后新开 root 登录 Shell 即可生效。

从 main 安装：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Elainaicey/keine/refs/heads/main/install.sh)
```

版本标签发布后，可将安装地址中的 `refs/heads/main` 替换为 `refs/tags/v0.5.2`。
