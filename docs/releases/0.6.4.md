# keine 0.6.4

0.6.4 优化应用、反向代理与证书管理的菜单一致性，不改变站点配置和证书签发逻辑。

- 普通菜单使用一致的按键和标题配色，运行状态、启停和删除继续保留语义颜色。
- 应用与容器的刷新入口移至独立操作区，分类标题保持统一。
- 刷新状态保留粉色快捷入口，按需重读服务快照，不新增后台轮询。
- 反向代理、证书、站点配置与软件组件增加分组标题。
- 安装不再重复确认目标目录；保留路径检查、卸载确认和失败回退。
- 反向代理首页、站点详情采用纵向排列，不随终端宽度切换为双列。
- 应用详情与证书中心的反代入口取消额外强调色，保留返回、首页与退出导航。

入口：`keine web`，或「应用与容器 → 反向代理与 HTTPS」。
