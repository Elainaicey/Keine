# keine 0.6.0

0.6.0 完善云主机防火墙适配、日常证书维护与独立网络调优方案，将管理入口连接到系统现有配置。

## 主机防火墙

- 识别 UFW、iptables/netfilter-persistent、nftables 与 firewalld，按实际后端显示操作入口。
- 在安装前识别 Oracle Cloud 及 UFW 与持久化组件的冲突，保留镜像原生规则。
- 原生 iptables 支持 IPv4/IPv6、批量端口与来源地址限制，以及托管规则的精确删除。
- 保留 OUTPUT、转发、NAT、云平台存储规则与默认策略；写入通过语法检查、互斥、运行验证和失败回退。
- 变更可从首次基线撤销；外部改动保留，当前 SSH 会话及 sshd 配置端口受保护。
- UFW 删除规则同样保护管理端口；SSH 换端口前确认原生防火墙和云端放行准备。

## TLS 与证书

- 分页浏览本机 Certbot 证书，显示剩余有效期、验证插件与证书路径。
- 按单张证书执行测试续期或手动续期，沿用原有插件和钩子；未发生更新时明确提示。
- 检查本地 PEM 证书，在线校验域名/IP、有效期与信任链。
- Nginx 应用详情的 HTTPS 入口连接证书中心。

## 交互与结构

- 新增 tcpfit / vps-tcp-tune 独立 sysctl 参数方案：统一差异预览、互斥切换、冲突检查与整组撤销，不拼接算法。
- 方案来源固定到审查提交，保留 MIT 声明；不随方案执行测速整形、换内核、路由钩子或计划任务，具体范围见 [网络调优方案](../NETWORK-ADAPTERS.md)。

- 运维总览、安全基线和暴露面分析识别原生防火墙，不再只依赖 UFW。
- Docker 发布端口明确提示转发规则与云端策略的核对边界。
- 防火墙与证书按后端、操作与菜单拆分，复用配置事务和统一导航。
- 单项软件更新增加禁止意外移除保护。

## 使用入口

```bash
keine firewall
keine certificates
keine tls example.com 443
keine tuning-adapters
```

原生端口写入要求已有并启用的 netfilter-persistent 以及有效的 `rules.v4` / `rules.v6`。nftables、firewalld 本次提供查看入口，不执行自动迁移。Certbot 测试和正式续期都可能运行原有钩子，操作前会显示影响并确认。

keine 继续完全按需运行，不创建后台监控或自动任务；历史快照仍由用户手动创建。

## 升级

使用项目安装入口更新程序；启用调优方案前先检查已有参数来源。工具不会接管未知第三方脚本的修改，切换托管方案不需要重新安装。

## 兼容性与变更

面向 Debian / Ubuntu 与系统原生工具。容器限制或内核缺失会阻止不受支持的写入；tcpfit 参数方案要求 4 KiB 内存页。具体权限、参数范围与恢复边界见 [网络调优方案](../NETWORK-ADAPTERS.md)。
