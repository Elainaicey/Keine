# keine 0.6.6

0.6.6 扩展安全中心的 SSH 登录与 root 公钥管理，并收录此前尚未发布的端口转发、FRP 和安装可靠性改进。

- root 公钥添加、单文件导入、SHA256 指纹去重、来源 IP/CIDR 与转发限制、启停、删除和首次基线恢复。
- 公钥写入互斥、原子替换、外部修改保护和失败回退；阻止移除最后一把可解析的启用公钥。
- SSH 登录方式切换、有效配置与公钥路径诊断；已有多因素认证要求保留。登录分析支持 1/24/168 小时及公钥、键盘交互失败事件。
- 新增 `keine ssh`、`keine ssh-keys`、`keine ssh-check`，安全中心、公钥和登录分析相互联动。
- `keine forward` 提供 socat/systemd TCP/UDP 转发、IPv4/IPv6、启停、开机策略和安全撤销。
- `keine frp` 提供官方 frps/frpc 安装、服务端/客户端配置、TCP/UDP 映射、运行验证、回退和整组撤销。
- 安装增加并发锁、暂存和启动校验、可捕获中断/失败回退；更新避免继承失效工作目录。
- 修复 OpenSSL 域名检查跨版本退出状态差异导致的错误证书匹配；反代与证书网络检查显式忽略 curl 默认配置。

## 升级

执行 `keine update`，或重新运行项目安装器。更新完成后重新加载菜单，`keine version` 应显示 `0.6.6`。本版本不自动添加公钥或收紧 SSH 登录，也不自动创建转发/FRP 服务。

## 兼容性与变更

继续面向 Debian/Ubuntu 单一 root 管理员，无旧名称兼容层。公钥只管理有效标准路径；自定义取钥、SSH CA 和其他账户保留原生管理。文件首次接管需要明确选择，后续外部改动停止覆盖；恢复公钥基线前需要确认其他登录手段。

安全流程已进行离线回归和原生公钥格式解析，未进行真实 VPS 登录、systemd、FRP/TCP/UDP 流量或跨地址族部署验证。保留当前会话及服务商控制台，在新窗口验证后再收紧认证。FRP 不提供自定义 CA 的服务端身份校验；实际范围见对应文档。
