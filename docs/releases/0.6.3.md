# keine 0.6.3

0.6.3 增加反向代理配置与 HTTPS 首次签发，将应用安装、站点配置、证书和恢复流程连接到现有控制台。

- **反向代理**：Nginx / Caddy 站点创建、修改、启停、删除；支持 WebSocket、HTTPS 上游、超时与上传限制。
- **HTTPS**：Certbot HTTP Webroot、手动 DNS 和通配符签发，已有证书部署及引用检查；Caddy 原生自动 HTTPS。
- **原生配置识别**：展开 Nginx include 和 Caddy import，已有外部配置只读展示，保留自定义规则。
- **恢复与验证**：原生配置检查、加载失败回退、首次基线和外部修改保护；删除站点保留证书与上游数据。

入口：`keine web`，或「应用与容器 → 反向代理与 HTTPS」。证书中心仍可通过 `keine certificates` 打开。

当前自动编辑范围为 keine 创建的标准站点；容器部署、Caddy API 恢复模式和复杂自定义路由保留原生管理。
keine 不新增自动任务；Caddy 自动 HTTPS 由 Caddy 服务本身提供，手动 DNS 证书需要交互续期。

完整用法见[反向代理与 HTTPS](../WEB.md)。
