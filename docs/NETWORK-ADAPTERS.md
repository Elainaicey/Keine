# 网络调优适配契约

## 当前能力

`keine tuning-adapters` 是第三方调优的预留入口。当前不绑定提供方，不下载、不执行外部脚本；可进入网络参数管理、查看持久配置来源以及撤销本项目参数。

原生网络设置与第三方脚本适配分离：DNS、SOCKS 客户端、BBR 和白名单参数由网络功能域实现；第三方集成位于 `src/integrations/`。新增上游无需改写 DNS 或代理逻辑。

## 注册与能力声明

每个提供方使用固定 ID，在 `config/integrations.tsv` 注册，并在 `integration_dispatch` 和仓库验证器中加入静态处理器白名单。注册数据不得包含 Shell 命令，不得通过 `eval` 或 `source` 加载远程内容。

适配器分别声明这些能力，不支持的能力必须显示为不可用：

| 能力 | 要求 |
| --- | --- |
| 探测 | 识别原生版本、文件和设置，区分“可观察”和“项目所有” |
| 状态 | 读取当前运行值及固定来源；不循环监控，不输出密钥 |
| 计划 | 列明键、文件、服务、内核、路由及 SSH 可能受到的影响 |
| 应用 | 固定经审查的上游与入口，验证下载来源及完整性，人工确认后执行 |
| 撤销 | 仅处理有原始记录、所有权和完整恢复方案的资源；外部冲突停止 |

没有可靠原始值或完整写入范围时，不提供“一键恢复默认”或“完全清除”操作。更换内核、引导项、路由或执行上游不透明安装器，需要独立风险说明和相应适配实现，不能继承原生参数的可逆承诺。

## 冲突与回退

接入前检查本项目网络参数与第三方声明是否重叠，建议先撤销重复设置。运行值来自内核，持久来源可能包含 `/etc/sysctl.conf` 和多个 `sysctl.d` 层级；来源列表只展示声明，不宣称自动计算了所有开机覆盖关系。

应用不得重新加载不相关的第三方文件。支持可逆的键需保存首次原始值和最后项目值；恢复前核对当前值，并将文件与运行值作为同一组处理。失败保留恢复记录，不通过删除记录掩盖未完成操作。

退出后不保留项目进程、Cron、Timer 或后台任务。离线验证使用系统临时目录，退出时清理夹具；回归源码保留在 `tests/`，不部署到 VPS。
